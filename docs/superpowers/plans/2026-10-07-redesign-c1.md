**Goal:** reskin EATRi8 in the C1 Lime & Ink direction and add the Progress tab, the full-page food search, the scan review and analysing steps, the simplified Me page and the credits activity page, all exactly as in the mock.

**Architecture:**

- **Screens:** each screen is rebuilt in place under `components/<area>/`. Pure logic (progress aggregation, icon map, stepper, activity grouping, balance series) goes in `lib/` with unit tests.

**Spec:** `docs/superpowers/specs/2026-10-07-redesign-c1-design.md`. The visual source of truth is `docs/design/mock-c1.html`; open it in a browser, and its sections are linked from the top. M2 leftovers are listed in `docs/superpowers/specs/m2-final-rereview.md`.

## Global Constraints

- **No wrapping:** buttons, chips, tabs and pills are `whitespace-nowrap` and never wrap at 360 px. Shorten the copy or use an icon instead.
- **Icons:** lucide icons on buttons, list rows, stat tiles, chips, flags and meal rows. Icons are `aria-hidden`; the text carries the meaning.
- **Lime is never text colour.** Text accents use `text-brand-deep`, and text on a lime fill uses `text-brand-ink`.
- **Grade colours mean A–E only.** Macro colours are `--protein` #2E7CF6, `--carbs` #7A5AF8 and `--fat` #D6408F.
- **One primary action per screen or sheet:** solid `--action` (ink in light mode, lime in dark mode). Secondary buttons are ghost on `--sunken`.
- **Tap targets ≥ 44 px.**
- **Colours come from tokens only.** No raw hex in components; hex values appear only in `app/globals.css`.
- **Motion respects `prefers-reduced-motion`.**
- **Each chart** has an `aria-label`, and its colours come from tokens.
- **Out of scope:** photo storage, food images, workouts, weight, notifications. Never add R2 or image fetching.
- **Money invariants from M2 stay untouched:** idempotency keys, debit before the model call, refund only charged scans, `FOR UPDATE` serialisation, conditional terminal writes.
- **Every commit** ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push. Never commit `.env.local`.
- **Before each commit:** `pnpm lint && pnpm typecheck && pnpm test`. Run `pnpm test:int` as well when a task touches `lib/` services or the API. `pnpm build` must pass at the end of every task.

## Review Focus

1. **Long food names** (for example "Haldiram's Aloo Bhujia Masala Namkeen 400 g") in search rows, sheet heads, meal summaries and activity rows. They should ellipsise, and buttons and grade badges must never be pushed out of place or wrapped. Covered by the long-name check in Task 10's audit pages and the `truncate` classes required in Tasks 3–7.
2. **A brand-new user with 0–1 days logged** opening Progress and Credits. They should see the empty state, never NaN, `Infinity` or empty charts. Tested in Task 6 (`summarize([])`) and Task 7 (activity with only a grant).
3. **Eating more than the target.** The Today headline should say "You're N kcal over today". The ring stays full and the label shows the true %. Tested in Task 3 (`headlineFor`).
4. **Dark mode.** Ink buttons become lime with dark text, lime is never used as text, and charts stay readable. Covered by Task 10's dark screenshots, and Task 1 defines every token in both themes.
5. **Timezone boundaries** for an IST user at 00:30. Progress days, streak and "Today/Yesterday" grouping must use the profile timezone and not UTC. Tested in Task 6 (streak) and Task 7 (`groupActivity`).

```ts
export type FoodIconKey = "package" | "drink" | "bowl" | "wheat" | "milk" | "egg" | "fruit" | "snack" | "default";

const RULES: [FoodIconKey, RegExp][] = [
  ["drink", /\b(chai|tea|coffee|lassi|juice|shake|smoothie|soda|cola|buttermilk|chaas|nimbu pani|sharbat)\b/],
  ["egg", /\b(egg|omelette|omelet|anda)\b/],
  ["wheat", /\b(roti|chapati|chapatti|phulka|paratha|naan|kulcha|bread|toast|puri|poori|bhatura|thepla)\b/],
  ["milk", /\b(milk|curd|dahi|yogurt|yoghurt|paneer|cheese|raita|kheer)\b/],
  ["snack", /\b(samosa|pakora|bhaji|namkeen|bhujia|biscuit|cookie|cake|chips|ladoo|laddu|jalebi|gulab jamun|barfi|halwa|mithai|chocolate|kachori)\b/],
  ["fruit", /\b(banana|apple|mango|orange|papaya|grapes|guava|watermelon|pomegranate|fruit|salad)\b/],
  ["bowl", /\b(dal|daal|rice|khichdi|curry|sabzi|sabji|rajma|chole|chana|sambar|rasam|biryani|pulao|poha|upma|soup|korma|makhani|kadhi|stew|bowl)\b/],
];

export function foodIconKey(f: { name: string; source: string; barcode?: string | null; gradeCategory?: string | null; categories?: string[] | null }): FoodIconKey {
  if (f.source === "off" || f.barcode) return "package";
  if (f.gradeCategory === "beverage" || f.gradeCategory === "water") return "drink";
  const text = [f.name, ...(f.categories ?? [])].join(" ").normalize("NFD").replace(/\p{Diacritic}/gu, "").toLowerCase();
  for (const [key, re] of RULES) if (re.test(text)) return key;
  return "default";
}
```

- [ ] **Step 2: Implement** `lib/today/headline.ts`

```ts
const fmt = (n: number) => `${Math.round(n).toLocaleString("en-IN")} kcal`;
export function headlineFor(p: { eaten: number; target: number; isToday: boolean; dateLabel: string }) {
  const diff = p.target - p.eaten;
  const over = diff < 0;
  if (p.isToday) return { lead: over ? "You're" : "You have", value: fmt(Math.abs(diff)), tail: over ? "over today" : "left today" };
  return { lead: "", value: fmt(Math.abs(diff)), tail: `${over ? "over" : "left"} on ${p.dateLabel}` };
}
```

Note: `toLocaleString("en-IN")` gives "1,050" for 4-digit values, which is what the test expects. The test does not cover 6-digit Indian grouping.

```ts
export async function loggedDates(userId: string, month: string): Promise<string[]> {
  if (!/^\d{4}-\d{2}$/.test(month)) throw new InvalidError();
  const start = `${month}-01`;
  const rows = await db.selectDistinct({ date: foodLog.date }).from(foodLog)
    .where(and(eq(foodLog.userId, userId), gte(foodLog.date, start), lt(foodLog.date, sql`(${start}::date + interval '1 month')::date`)))
    .orderBy(foodLog.date);
  return rows.map((r) => r.date);
}
```

```ts
export function stepFor(unit: PortionUnit): number { return unit === "g" || unit === "ml" ? 10 : 0.5; }
export function stepAmount(amount: number, unit: PortionUnit, dir: 1 | -1): number {
  const s = stepFor(unit);
  const snapped = dir === 1 ? Math.floor(amount / s + 1e-9) * s + s : Math.ceil(amount / s - 1e-9) * s - s;
  return Math.max(s, Math.round(snapped * 100) / 100);
}
export function formatAmount(n: number): string {
  const whole = Math.floor(n), frac = Math.round((n - whole) * 100) / 100;
  if (frac === 0.5) return whole ? `${whole}½` : "½";
  return Number.isInteger(n) ? String(n) : String(Math.round(n * 100) / 100);
}
```

```ts
import { addDays } from "@/lib/dates";
import type { DailyTargets, Goal, Grade } from "@/lib/nutrition/types";

export interface DayAgg { date: string; kcal: number; protein: number; carbs: number; fat: number; fibre: number; sugars: number; sodiumMg: number; satFat: number; entries: number; gradeKcal: Partial<Record<Grade, number>> }
export type Range = "week" | "month";
export interface ProgressSummary {
  range: Range; days: DayAgg[]; targets: DailyTargets;
  kpis: { avgKcal: number; avgProtein: number; daysOnTarget: number; daysLogged: number; streak: number };
  macroSplit: { protein: number; carbs: number; fat: number };
  balance: { protein: number; fibre: number; energy: number; sugars: number; sodium: number; satFat: number };
  gradeMix: Record<Grade, number>;
  worstOverLimit: { axis: "sugars" | "sodium" | "satFat"; pct: number } | null;
}
const GRADES: Grade[] = ["A", "B", "C", "D", "E"];
export const rangeDays = (r: Range) => (r === "week" ? 7 : 30);
const empty = (date: string): DayAgg => ({ date, kcal: 0, protein: 0, carbs: 0, fat: 0, fibre: 0, sugars: 0, sodiumMg: 0, satFat: 0, entries: 0, gradeKcal: {} });
const pct = (v: number, t: number) => (t > 0 ? Math.round((v / t) * 100) : 0);

export function onTargetRange(goal: Goal): [number, number] { return goal === "weight_loss" ? [0.8, 1.0] : [0.9, 1.1]; }

export function streakEnding(dates: Set<string>, today: string): number {
  let d = dates.has(today) ? today : addDays(today, -1);
  let n = 0;
  while (dates.has(d)) { n++; d = addDays(d, -1); }
  return n;
}

function roundTo100(parts: number[]): number[] {
  const total = parts.reduce((a, b) => a + b, 0);
  if (total <= 0) return parts.map(() => 0);
  const raw = parts.map((p) => (p / total) * 100);
  const floored = raw.map(Math.floor);
  let rest = 100 - floored.reduce((a, b) => a + b, 0);
  const order = raw.map((r, i) => [r - floored[i], i] as const).sort((a, b) => b[0] - a[0]);
  for (const [, i] of order) { if (rest-- <= 0) break; floored[i]++; }
  return floored;
}

export function summarize(rows: DayAgg[], targets: DailyTargets, goal: Goal, today: string, range: Range): ProgressSummary {
  const n = rangeDays(range);
  const byDate = new Map(rows.map((r) => [r.date, r]));
  const days = Array.from({ length: n }, (_, i) => byDate.get(addDays(today, i - (n - 1))) ?? empty(addDays(today, i - (n - 1))));
  const logged = days.filter((d) => d.entries > 0);
  const L = logged.length;
  const avg = (k: keyof Omit<DayAgg, "date" | "entries" | "gradeKcal">) => (L ? logged.reduce((a, d) => a + d[k], 0) / L : 0);
  const [lo, hi] = onTargetRange(goal);
  const daysOnTarget = logged.filter((d) => d.kcal >= targets.energyKcal * lo && d.kcal <= targets.energyKcal * hi).length;
  const [p, c, f] = roundTo100([avg("protein") * 4, avg("carbs") * 4, avg("fat") * 9]);
  const raw = {
    protein: pct(avg("protein"), targets.protein), fibre: pct(avg("fibre"), targets.fibre), energy: pct(avg("kcal"), targets.energyKcal),
    sugars: pct(avg("sugars"), targets.sugarsMax), sodium: pct(avg("sodiumMg"), targets.sodiumMgMax), satFat: pct(avg("satFat"), targets.satFatMax),
  };
  const balance = Object.fromEntries(Object.entries(raw).map(([k, v]) => [k, Math.min(150, v)])) as ProgressSummary["balance"];
  const limits = (["sugars", "sodium", "satFat"] as const).filter((k) => raw[k] > 100).sort((a, b) => raw[b] - raw[a]);
  const gk = GRADES.map((g) => logged.reduce((a, d) => a + (d.gradeKcal[g] ?? 0), 0));
  const mix = roundTo100(gk);
  return {
    range, days, targets,
    kpis: { avgKcal: Math.round(avg("kcal")), avgProtein: Math.round(avg("protein")), daysOnTarget, daysLogged: L, streak: streakEnding(new Set(rows.filter((r) => r.entries > 0).map((r) => r.date)), today) },
    macroSplit: { protein: p, carbs: c, fat: f },
    balance,
    gradeMix: Object.fromEntries(GRADES.map((g, i) => [g, mix[i]])) as Record<Grade, number>,
    worstOverLimit: limits.length ? { axis: limits[0], pct: raw[limits[0]] } : null,
  };
}
```

```ts
    gE: sql<number>`coalesce(sum(${kcal}) filter (where ${foodLog.grade} = 'E'), 0)`,
  }).from(foodLog).where(and(eq(foodLog.userId, userId), gte(foodLog.date, start), lte(foodLog.date, today))).groupBy(foodLog.date);
  const days: DayAgg[] = rows.map((r) => ({
    date: r.date, entries: Number(r.entries), kcal: Number(r.kcal), protein: Number(r.protein), carbs: Number(r.carbs), fat: Number(r.fat),
    fibre: Number(r.fibre), sugars: Number(r.sugars), sodiumMg: Number(r.sodiumMg), satFat: Number(r.satFat),
    gradeKcal: { A: Number(r.gA), B: Number(r.gB), C: Number(r.gC), D: Number(r.gD), E: Number(r.gE) },
  }));
  return summarize(days, targetsFor(prof.goal, prof.targets), prof.goal, today, range);
}
```

```ts
import { addDays, todayIn } from "@/lib/dates";
export type ActivityKind = "used" | "free" | "refund" | "grant";
export interface ActivityItem { id: string; kind: ActivityKind; at: string; title: string; meta: string; amount: number; scanId: string | null; linkable: boolean }
const MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];
const dayLabel = (d: string) => `${Number(d.slice(8))} ${MONTHS[Number(d.slice(5, 7)) - 1]}`;

export function groupActivity(items: ActivityItem[], tz: string, now: Date) {
  const today = todayIn(tz, now), yesterday = addDays(today, -1);
  const sorted = [...items].sort((a, b) => b.at.localeCompare(a.at));
  const groups: { label: string; items: ActivityItem[] }[] = [];
  for (const it of sorted) {
    const d = todayIn(tz, new Date(it.at));
    const label = d === today ? "Today" : d === yesterday ? "Yesterday" : dayLabel(d);
    const last = groups.at(-1);
    if (last && last.label === label) last.items.push(it); else groups.push({ label, items: [it] });
  }
  return groups;
}

export function balanceSeries(txns: { at: string; balanceAfter: number }[], periodStart: string, today: string, tz: string, startBalance: number) {
  const lastByDay = new Map<string, number>();
  for (const t of [...txns].sort((a, b) => a.at.localeCompare(b.at))) lastByDay.set(todayIn(tz, new Date(t.at)), t.balanceAfter);
  const out: { date: string; balance: number; event: boolean }[] = [];
  let bal = startBalance;
  for (let d = periodStart; d <= today; d = addDays(d, 1)) {
    const ev = lastByDay.has(d);
    if (ev) bal = lastByDay.get(d)!;
    out.push({ date: d, balance: bal, event: ev });
  }
  return out;
}
```
