# Phase 2: R2 Photos, Pro Gating and the Fitness Tracker (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship three things from the spec:
- scan photos stored on R2
- Basic vs Pro gating that works end to end, with a waitlist and no payments
- a gym-first fitness tracker with workout logging, weight tracking and energy balance

**Architecture:**
- **R2:** an optional `PhotoStore`. The R2 version uses aws4fetch; tests use an in-memory fake. Images are processed with sharp in the existing post-charge `after()`.
- **Pro gating:** finishes the existing `allows()` launch switch, adding locks, an upgrade sheet, CSV export and the targets reset.
- **Fitness:** four new tables and the pure modules `lib/fitness/{catalogue,burn,stats}.ts`, plus owner-scoped APIs. The screens follow the mock's Fitness section.

**Tech stack:** Next 16, React 19, Drizzle/Postgres, TanStack Query, EvilCharts (Recharts), sharp, aws4fetch, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-08-phase-2-design.md`. Visual reference: `docs/design/mock-c1.html` (sections "Scan flow" and "Fitness").

## Global Constraints
- **Styling:** tokens only (no raw hex outside globals.css and the icon files). Buttons, chips, tabs and set inputs never wrap. Tap targets are at least 44 px. Icons are lucide with `aria-hidden`. No lime text. Dark is the default theme, and light must work too.
- **Money paths stay untouched:** idempotency, debit before the model call, refund only on charged scans, `FOR UPDATE`, conditional terminal writes.
- **Everything is owner-scoped.** Soft delete applies to user-facing records.
- **Migrations are numbered 0008, 0009 and 0010,** generated with drizzle-kit and checked with `drizzle-kit check`.
- **Before each commit:** `pnpm lint && pnpm typecheck && pnpm test`, plus `pnpm test:int` when `lib/` or the API changes.
- **Every task ends with:**
  - `pnpm build` (stop dev first, then restart it with `nohup pnpm dev > /dev/null 2>&1 &` and check that /sign-in returns 200)
  - `pnpm ui:audit` with 0 offenders and 0 errors (run `pnpm seed:demo` first if the day has rolled over)
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push. Never touch other users' data.

## Review Focus
1. **A gym session lost to a reload or app switch.** The draft must survive. Covered in Task 4: the localStorage draft and the resume banner.
2. **No body weight logged.** The burn falls back to an estimate of 70 kg, marked "~", and never shows NaN. Tested in Task 3.
3. **Week boundaries for an IST user at 00:30 on a Monday.** The new week starts on that Monday. Tested in Task 3.
4. **R2 disabled (no env) or failing.** Scans still succeed and charge exactly once, and no photo UI appears. Tested in Task 1.
5. **Pro gates enforced and the user is on Basic.** Every gated entry point opens the upgrade sheet, and the API refuses with 403. Tested in Task 2.

- [ ] **Step 1: test** `lib/fitness/burn.test.ts`:

```ts
import { describe, expect, it } from "vitest";
import { kcalBurned, met } from "./burn";
describe("burn", () => {
  it("uses the spec's MET table", () => {
    expect(met("gym", "moderate")).toBe(5.0);
    expect(met("walk", "hard")).toBe(4.3);
    expect(met("run", "moderate")).toBe(9.8);
    expect(met("yoga", "easy")).toBe(2.5);
  });
  it("is MET × kg × hours, rounded", () => {
    expect(kcalBurned({ kind: "walk", intensity: "moderate", minutes: 35, weightKg: 72 })).toEqual({ kcal: 147, estimated: false, weightKg: 72, met: 3.5 });
  });
  it("estimates with 70 kg when no weight is logged", () => {
    expect(kcalBurned({ kind: "gym", intensity: "moderate", minutes: 48, weightKg: null })).toMatchObject({ kcal: 280, estimated: true, weightKg: 70 });
  });
  it("never returns NaN for zero or bad minutes", () => {
    expect(kcalBurned({ kind: "run", intensity: "easy", minutes: 0, weightKg: 70 }).kcal).toBe(0);
  });
});
```

describe("stats", () => {

    expect(volume([{ weightKg: 60, reps: 8, done: true }, { weightKg: 60, reps: 8, done: false }, { weightKg: null, reps: 10, done: true }])).toBe(480);
